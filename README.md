# IT-Help-Desk-Troubleshooting-Lab

## Project Overview
This project demonstrates basic Windows IT troubleshooting skills through hands-on exercises involving network connectivity, computer performance, printer settings, running applications, and account security settings.

## Objective
The goal of this lab was to practice common IT help desk troubleshooting tasks and become familiar with Windows tools used to identify basic computer issues.

## Tools Used
- Windows 11
- Command Prompt
- Windows Task Manager
- Control Panel
- Windows Settings

## Skills Demonstrated
- Windows troubleshooting
- Basic networking
- Command Prompt
- IP configuration
- Ping connectivity testing
- System performance monitoring
- Application management
- Printer settings
- Windows account security

## What I Learned
I learned how to use built-in Windows tools to investigate common computer issues, check network connectivity, monitor system performance, and review account security settings.

The troubleshooting exercises helped me gain hands-on experience with basic IT support tasks and understand how to use Windows tools to investigate common technical issues.
