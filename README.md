# IT-Help-Desk-Troubleshooting-Lab
A hands-on Windows IT troubleshooting lab covering network connectivity, system performance, printer settings, application troubleshooting, and user account management.


## Project Overview
This project demonstrates basic Windows IT troubleshooting skills through hands-on exercises involving network connectivity, computer performance, printer settings, running applications, and account security settings.

## Objective
The goal of this lab was to practice common IT help desk troubleshooting tasks and become familiar with Windows tools used to identify basic computer issues.

## Tools Used
- Windows 11
- Command Prompt
- Windows Task Manager
- Control Panel
- Windows Settings

## Troubleshooting Tasks

### 1. Internet Connection
- Used `ipconfig` to review network configuration.
- Used `ping 8.8.8.8` to test connectivity.
- Received four successful replies with 0% packet loss.

### 2. Computer Performance
- Used Task Manager to monitor CPU, memory, and disk usage.
- Observed approximately 2% CPU usage and 56% memory usage.

### 3. Printer Settings
- Opened Control Panel and Devices and Printers.
- Identified Microsoft Print to PDF and OneNote (Desktop).
- No physical printer was available for testing.

### 4. Application Management
- Used Task Manager to review running applications.
- Checked for applications that were not responding.
- No frozen applications were identified.

### 5. Account Security Settings
- Navigated to Windows Settings > Accounts > Sign-in options.
- Reviewed available Windows Hello sign-in methods.
- Identified sign-in methods that were unavailable.
